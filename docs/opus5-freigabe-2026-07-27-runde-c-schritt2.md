Die Testzahl ist um sechs gefallen. „Asset-Assertion auf die Rest-Stapel-Bilder umgestellt"
erklärt geänderte Tests, aber nicht sechs **verschwundene**.

**Bitte im selben Bericht auflösen:** welche sechs Tests sind entfallen, und ist jede Zusage,
die sie geprüft haben, heute anderswo abgedeckt? Wenn ja: eine Zeile je Test genügt. Wenn nein:
nachziehen, bevor der Commit steht.

Das ist keine Beanstandung — es ist die Stelle, an der Abdeckung still verschwindet, wenn
niemand hinsieht. Vier Runden vor Go-Live ist Stillschweigen darüber teurer als die fünf
Minuten, es aufzuschreiben.
